NOTE: DirectX uses a left-handed coordinate system compared to OpenGL,
but HLSL still uses column-major ordering like what GLSL does.

Its math library, DirectXMath, uses row-major ordering for processing,
since that's how C and C++ lay out their data successively
(define an array in C++ and split it in newlines into a 2D grid to see why).

However, the matrix data (e.g. projection/view matrices)
is filled out in column-major ordering,
like what you'd see in most math textbooks,
since you multiply vectors as columns.
